# 초코의 일상 (가제) — 반려동물 기록 앱

디자인 캔버스 「초코의 일상 앱 컨셉」을 실제로 동작하는 앱으로 만든 것입니다.
아이폰·안드로이드 브라우저에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요 (PWA).

## 주소
GitHub Pages를 켜 둔 상태라면 기존 주소 뒤에 `/pet-app/`을 붙이면 됩니다.
`https://사용자이름.github.io/hyeonu-stock-screener/pet-app/`

아이폰: Safari로 열기 → 공유 버튼 → **홈 화면에 추가**

## 들어있는 기능
| 화면 | 기능 |
|---|---|
| 시작 · 캐릭터 고르기 | 대표 6종(말티즈·푸들·골든리트리버·치즈냥·검정냥·삼색냥) × 털색 8가지, 이름·생일·만난 날·성별·중성화 |
| 홈 | 판자집 속 캐릭터가 걷고 앉고 랜덤 멘트, 누르면 반응, 시간이 지나면 집이 더러워지고 청소하면 보너스 코인 |
| 채팅 기록 | 식사 → (사료 g → 칼로리 자동 계산) → (간식 알레르기 경고) → 물 → 배변 → 산책/놀이 → (노령 모드: 관절·인지) → 특이사항. 항목별 코인 |
| 나의 동물 | 여러 마리 등록, 체중 그래프(1~36개월), 접종·약 마지막 날짜 → 다음 권장일 D-day 자동 계산, 노령 모드(나이에 맞춰 자동), 하루 권장 칼로리(참고용) |
| 정보 수정 | 질환·알레르기 칩, 주력 사료 원재료 알레르기 자동 확인 |
| 캘린더 | 월별 기록 표시(밥·산책·구토·주사·병원 등), 날짜별 상세, 일정 추가 |
| 병원 리포트 | 1주/2주/1개월/직접 기간, 구토·설사·음수량·식사·체중 변화 감지, 이미지 저장, 카카오톡 등으로 공유 |
| 알림 | 밥·산책 기록 누락, 접종 D-3, 내일 일정, 주간 특이사항, 청결 |
| 상점 | 집 꾸미기(벽지·바닥·벽난로·방석), 밈 코스튬(바나나 수트·앵그리 캡·하트 안경 등) 미리 입어보기와 구매 확인 |
| 설정 | 알림 켜고 끄기, 질문 항목 관리, 대사 빈도, 데이터 백업/불러오기, 전체 삭제 |

## 알아둘 점
- **서버가 없어요.** 모든 기록은 그 휴대폰 브라우저 안에만 저장돼요. 기기를 바꾸거나 브라우저 데이터를 지우기 전에 설정 › 데이터 백업을 해 두세요.
- **휴대폰 알림**은 앱을 열었을 때 새로 생긴 알림을 보내는 방식이에요. 앱이 완전히 닫혀 있을 때 오는 푸시 알림은 서버가 있어야 해서 아직 없어요. (아이폰은 홈 화면에 추가한 앱에서만 알림 권한을 줄 수 있어요.)
- 사료 검색 DB는 없어서 사료 이름·칼로리(kcal/kg)·원재료는 포장지를 보고 직접 입력해요.
- 얼굴 촬영 가이드는 디자인에서 "추후 추가 기능"으로 표시돼 있어 이번에는 넣지 않았어요.
- 리포트와 칼로리는 보호자 기록 기반 참고 자료이며 진단이 아니에요.

## 파일 구조
```
pet-app/
  index.html            앱 진입점
  css/app.css           디자인 (캔버스 색·폰트 그대로)
  js/app.js             화면 전환(라우터)·이벤트
  js/store.js           데이터 저장, 날짜·D-day·리포트 분석·알림 계산
  js/characters.js      캐릭터 SVG (종류·털색·표정·코스튬)
  js/lines.js           캐릭터 멘트
  js/screens/*.js       화면별 코드
  sw.js                 오프라인 캐시
```
로컬에서 확인: 저장소 루트에서 `python3 -m http.server` 실행 후 `http://localhost:8000/pet-app/`

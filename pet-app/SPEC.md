## 1. 앱 콘셉트

- 반려동물을 닮은 **캐릭터와 대화하듯 하루 기록**을 남기고, 그 기록으로 **건강 관리**(체중, 접종 일정, 병원 리포트)를 돕는 앱. **[디자인]**
- 기록하면 **코인**을 받고, 코인으로 캐릭터의 **집을 꾸미거나 코스튬**을 사는 보상 구조. **[디자인]**
- 캐릭터의 성격: **억울하지만 주인을 좋아하는** 반말 말투. 기본 표정은 눈썹이 찌푸려지고 눈물이 글썽입니다. **[디자인]**
- 캐릭터가 사는 집은 **바람 새는 낡은 판자집**이고, 상점에서 꾸밀수록 따뜻해집니다. **[디자인]**
- 강아지와 고양이를 모두 지원하고, 여러 마리를 등록할 수 있습니다. **[디자인]** 캐릭터 고르기 화면에 고양이 3종이 있고, 목록 화면에 둘째(콩이)가 있습니다.
- 앱 이름: 새 이름은 정하지 않았습니다. **[미결정]**

## 3. 화면별 기능

### 3-1. 캐릭터 고르기 [디자인]
- 위쪽에 큰 캐릭터 미리보기와 말풍선 **"주인아... 나로 정한 거냐..."**, 그 아래 "말티즈 · 흰색"처럼 현재 선택을 표시합니다.
- **강아지 3종**: 말티즈, 푸들, 골든리트리버
- **고양이 3종**: 치즈냥, 검정냥, 삼색냥
- **털색 8가지**("눌러서 바꿔요"): 흰색, 크림, 살구, 갈색, 초코, 검정, 회색, 황금
- 아래쪽 버튼: "다음: 이름 정하기"

### 3-2. 이름·기본 정보 [구현, 항목은 디자인의 정보 수정 화면 기준]
- 이름(필수), 품종, 생일, 만난 날, 성별(남/여), 중성화(O/X)
- 캐릭터 말풍선 예: "이름 예쁘게 지어줘라... 부탁이다..." [구현]

### 3-3. 홈 [디자인]
- 위쪽 줄: **코인** 알약 모양(예: 345), **알림 종**(안 읽으면 빨간 점), **설정**
- 동물 이름 + "(첫째) ▾": 눌러서 다른 동물로 바꿉니다
- 정보 줄: "말티즈 · 3살 · 함께한 지 242일 째"
- 가운데 **집 장면**: 하늘 그라데이션, 구름, 판자집(지붕 구멍, 벽 구멍, 문, 창문 구멍), 바람 줄무늬, 땅, 돌길, 물그릇, 그 위의 캐릭터와 말풍선
- 아래쪽 **대화 카드**: 캐릭터 얼굴 + "초코와 대화하기" + "초코가 오늘 밥 얘기가 하고 싶대요" + 갈색 원형 화살표 버튼
- **캐릭터 자동 움직임과 멘트** [디자인 CharacterMotion]

  | 상황 | 멘트 |
  |---|---|
  | 평소 · 걷기 | 어디 가냐고? 나도 몰라... |
  | 평소 · 앉기 | 주인아... 바람 새서 입 돌아간다... |
  | 밥 주기 | 이걸 먹으라고? ...맛있네. |
  | 밤 시간 | 5분만... 아니 5시간만... |
  | 기록 완료 | 기록했네?! 나 칭찬해줘!! |
  | 특이사항 기록 | 어디 아픈 거 아니지...? 병원 가자... |
  | (홈 예시) | 오늘 산책 시간... 아니면 벽 새로 할까? |

- [구현] 세부 동작
  - 걷기와 앉기를 9초마다 바꿉니다. 밤(23시~6시)에는 자는 표정입니다.
  - 캐릭터를 누르면 웃으며 뛰고 반응 멘트("왜 찌르냐...", "...한 번 더 해." 등)를 합니다.
  - 랜덤 멘트는 시간대(아침, 밤), 집 상태(장식이 없으면 추운 멘트, 벽난로가 있으면 따뜻한 멘트, 더러우면 청소 멘트), 코스튬(바나나 수트)에 따라 고릅니다.
  - 대화 카드 문구는 오늘 기록 진행 상태(예: "오늘 기록 2/5 · 이어서 알려줘", "오늘 기록 완료!")에 따라 바뀝니다.
- **집 청결도** [디자인: 알림 화면의 "청결 60% · 접속해서 청소하면 보너스 코인!", "복귀 보상 · 청소 완료 · +20 코인"]
  - [구현] 시간당 0.6%씩 떨어집니다(하루 약 14%). 90% 미만이면 바닥에 얼룩이 생기고 "청소하기 · 청결 N%" 버튼이 나옵니다.
  - [구현] 청소 보너스는 청결 70% 미만이면 +20코인(복귀 보상), 90% 미만이면 +5코인입니다.

### 3-4. 채팅 기록 (하루 기록) [디자인]
- 홈 화면 위에 대화창이 열리는 형태입니다. 위쪽에 "초코 · 오늘 기록 중 (5/5)"와 진행 칩(식사 ✓, 음수량 ✓, 배변 ✓, 산책 ✓, 특이사항)이 있습니다.
- 캐릭터가 묻고 사용자는 **버튼(칩)**으로 답합니다. 직접 입력칸과 보내기 버튼도 있습니다.
- 질문 순서와 선택지

  | 순서 | 질문 | 선택지 | 출처 |
  |---|---|---|---|
  | 1 | 식사 | 안 먹음 / 적게 / 보통 / 많이 | 항목은 [디자인], 선택지는 [구현] (캘린더 디자인에 "보통 · 220kcal") |
  | 1-a | 사료 g (사료 칼로리가 입력돼 있을 때) | 숫자 / 모름 → kcal 자동 계산 | [디자인] 정보 수정 화면 "이 정보로 식사 기록 시 칼로리를 계산해요 (1g당 3.65kcal)" |
  | 1-b | 간식 (알레르기가 등록돼 있을 때) | 없음 / 직접 입력 → 알레르기 성분이면 경고 | [디자인] "질환 · 알레르기 (홈 식사 기록에서 경고돼요)" |
  | 2 | 음수량 | 적게 / 보통 / 많이 | 항목 [디자인], 선택지 [구현] (캘린더 디자인에 "많이") |
  | 3 | 배변 | 정상 / 묽음 / 설사 / 변비 / 안 함 | 항목 [디자인], 선택지 [구현] (캘린더 디자인에 "정상") |
  | 4 | 산책 (고양이는 "놀이") | 안 함 / 10분 / 20분 / 30분 / 1시간 / 직접 입력 | 질문 문구 [디자인] "산책은 갔다 왔냐? 억울하다 진짜...", 선택지 [구현] |
  | 5 | (노령 모드) 관절, 인지 | 괜찮음/조금/많이, 없음/가끔/자주 | 노령 모드 질문 추가는 [디자인], 질문 내용 [구현] |
  | 6 | 특이사항 (여러 개 선택) | 구토 / 설사 / 발작 / 식욕부진 / 절뚝거림 / 기침 / 멀쩡함 / 기타 + 직접 입력 + "선택 완료" | [디자인] "마지막이다. 특이사항 있냐? 해당되는 거 다 눌러봐" |

- 기록하면 회색 안내 줄로 결과를 보여 줍니다(예: "자동 기록 · 산책 30분 · +5 코인"). **[디자인]**
- [구현] 세부 규칙
  - 답마다 캐릭터가 반응 멘트를 합니다.
  - "발작"을 고르면 바로 병원에 연락하라는 경고를 띄웁니다.
  - 과거 날짜도 캘린더에서 들어가 기록할 수 있습니다.
  - 다 기록한 뒤에는 "병원 리포트 보기 / 홈으로 / 처음부터 다시 기록하기"가 나옵니다.

### 3-5. 코인 규칙
- 산책 30분 +5코인 **[디자인]**, 청소 복귀 보상 +20코인 **[디자인]**
- [구현] 나머지 규칙
  - 식사·물·배변·특이사항은 각 +2, 관절·인지는 각 +1, 하루 기록 완료는 +10입니다.
  - **오늘 날짜 기록에만, 항목마다 한 번씩** 줍니다.
  - 시작 코인은 100입니다.

### 3-6. 나의 동물

**목록** [디자인]
- 동물마다 카드 하나: 얼굴(원형), 이름, "말티즈 / 3살 / 남", 수정 버튼(연필)
- "알림" 줄에 질환·알레르기 칩(빨강): 예) 슬개골 탈구, 닭고기 알레르기
- 최근 체중 미니 그래프 + "4.2kg (다이어트 순항 중!)"
- 가장 가까운 일정 알약(예: "심장사상충 약 D-3") + "상세 보기 ›"
- 오른쪽 위 "+ 추가"

**상세** [디자인]
- 이름, "말티즈 / 3살 / 남 · 중성화", "함께한 지 242일 째"
- **노령견 모드** 스위치: "관절, 인지 변화 질문이 채팅에 추가돼요"
  - 설정 화면 디자인에 "노령견 모드 (나이에 맞춰 자동)"이 있습니다.
  - [구현] 자동 기준은 강아지 7살, 고양이 10살입니다. 고양이는 "노령묘 모드"로 표시합니다.
- **체중 변화** 그래프와 "+ 체중 등록", 기간(개월) **1 / 3 / 6 / 12 / 24 / 36**
- **건강검진 · 접종** 목록과 "+ 날짜 입력": "마지막 날짜를 넣으면 다음 권장일과 알림이 자동 계산돼요". 항목마다 "마지막 날짜 → 다음 날짜"와 D-day 알약을 보여 줍니다.
  - 디자인 예시 항목: 심장사상충 약, 종합백신, 건강검진, 광견병 접종
  - [구현] 기본 주기는 심장사상충 약 30일, 종합백신 365일, 광견병 365일, 건강검진 365일, 내부 구충제 90일, 외부 기생충 약 30일, 스케일링 365일입니다. 항목마다 주기를 직접 바꿀 수 있습니다.
  - D-day 색은 디자인 예시를 따릅니다: D-3은 빨강, D-24는 파랑, D-139 이상은 회갈색. [구현] 기준선은 3일 이하 빨강, 30일 이하 파랑, 그 외 회색입니다.
- **주력 사료**: 사료 이름, "하루 권장 약 280kcal", "닭고기 성분 없음"(초록 칩)
  - [구현] 권장 칼로리 = 70 × 체중^0.75 × 계수(10단위 반올림, 참고용). 계수는 강아지 중성화 1.6 / 미중성화 1.8, 고양이 중성화 1.2 / 미중성화 1.4, 노령 강아지 1.4 / 노령 고양이 1.1입니다.

**정보 수정** [디자인]
- 얼굴, 이름, 품종, 생일, 만난 날, 성별(남/여), 중성화(O/X)
- 질환·알레르기 칩(× 삭제, "+ 추가"): "홈 식사 기록에서 경고돼요"
- **주력 사료 검색**: 검색어를 입력하면 결과 목록이 나옵니다(브랜드, 단백질·지방 %, kcal/kg). 고른 사료의 원재료를 보여 주고 "닭고기 없음 · 초코 알레르기 안전"(초록), "완두 포함 · 참고"(노랑) 칩을 붙이며, "이 정보로 식사 기록 시 칼로리를 계산해요"라고 안내합니다.
  - 첫 버전에서는 **사료 데이터베이스가 없어서** 사료 이름, kcal/kg, 원재료를 직접 입력하는 방식으로 대신했습니다. **[구현]** 실제 사료 DB를 어떻게 마련할지는 정하지 않았습니다. **[미결정]**

### 3-7. 캘린더 [디자인]
- 위쪽: "‹ 2026년 10월 ›", "+ 일정", 동물 선택 "초코 ▾"
- 배너: "병원 리포트 공유 · 변화 감지 · 최근 2주 구토 3회 · 리포트 ›"
- 달력 칸 안에 작은 표시: **밥, 산책, 구토, 주사, 병원** 등
- 날짜를 누르면 아래 카드에 "10월 20일 (화) 기록 · 채팅 보기"와 식사(보통 · 220kcal), 음수량(많이), 배변(정상), 산책(30분 · +5 코인), 특이사항(구토 1회), 일정(동물병원 14:00)을 보여 줍니다.
- [구현] 일정 추가 항목은 종류(병원/주사/약/미용/기타), 내용, 날짜, 시간입니다. 접종 예정일도 달력에 "예정"으로 보여 줍니다.

### 3-8. 병원 리포트 [디자인]
- 기간: **1주 / 2주 / 1개월 / 직접**
- 제목 "초코 건강 리포트", 기간과 기본 정보("10/14 ~ 10/27 (2주) · 말티즈 3살 남 · 알레르기: 닭고기")
- **변화 감지** 예시
  - 구토 3회 (10/16 · 10/20 · 10/24)
  - 음수량 "많이" 4일 (이전 2주 평균보다 늘었어요)
  - 식사 "적게" 2일 (10/21~22) · 나머지 날은 보통
  - 체중 4.4 → 4.2kg (-4.5%)
  - 산책 평균 32분 · 기록 12일
- 그래프가 있고, 문구 **"보호자 기록 기반 참고 자료예요. 진단이 아니며, 증상이 계속되면 병원 상담을 권해요."**가 들어갑니다.
- 버튼: **이미지로 저장**, **카카오톡으로 공유**, 오른쪽 위 "공유"
- [구현] 기준
  - 체중 5% 이상 변화를 주의로 표시합니다.
  - 그래프는 날짜별 띠 그래프(정상/특이사항/기록 없음)로 만들었습니다.
  - 카카오톡 공유는 카카오 SDK 대신 휴대폰 공유 시트(Web Share)로 처리했습니다.

### 4-3. 모양과 레이아웃
- 기준 화면 크기는 **390×844**(휴대폰)입니다.

- **상단 바**: 하늘색 바탕, 아래 3px 테두리, 높이 약 68px. 왼쪽에 원형 뒤로 버튼(‹), 오른쪽에 원형 아이콘 버튼
- **하단 메뉴**: 위 3px 테두리, 크림 바탕, 칸 높이 60px, 아이콘 위 + 글자 아래. 선택된 칸은 하늘색 바탕
- **강조 버튼(저장 등)**: 노랑 바탕, 3px 테두리, 아래로 3px 그림자(눌리는 느낌)
- **말풍선**: 흰 바탕, 3px 테두리, 큰 둥근 모서리, 꼬리는 작은 원
- **터치 영역은 최소 44px**입니다.

## 5. 구현 방식 (첫 버전) [구현]

다시 만들 때 바꿔도 되는 부분입니다.
- **설치형 웹앱(PWA)**: 휴대폰 브라우저에서 열고 "홈 화면에 추가"로 앱처럼 씁니다. HTML/CSS/JavaScript만 쓰고 빌드 도구는 없습니다. 오프라인에서도 열리도록 앱 파일을 캐시합니다.
- **데이터는 기기 안에만 저장**(브라우저 저장소)합니다. 서버와 로그인이 없고, 설정에서 백업 파일로 내보내고 불러옵니다.
- 리포트 이미지는 화면을 그림으로 바꿔 저장합니다. 공유는 휴대폰 공유 시트를 씁니다.
- 앱 아이콘은 바나나 수트를 입은 말티즈 캐릭터입니다.

## 6. 대화에서 논의했지만 정하지 않은 것 [미결정]

1. **실제 사용자 데이터를 받는 서비스로 만들기** [대화]
   - 사용자는 "진짜 사용자들의 데이터를 받는 앱을 만들 거라"고 했습니다.
   - 그러려면 서버, 데이터베이스, 로그인, HTTPS 주소, 앱의 저장 방식 변경이 필요합니다.
   - 이용자 정보를 해외 서버에 두면 한국 개인정보보호법의 국외 이전 의무(고지와 동의 등)가 생길 수 있다고 안내했습니다. 전문가 확인은 받지 않았습니다.
   - 서비스로 낸다면 개인정보처리방침, 이용약관, 가입 동의 화면, 비밀번호 보호(또는 소셜 로그인), 탈퇴 시 삭제, 백업이 필요합니다.
   - 저장 방식 선택지로 ① 기기 저장 + 백업, ② 직접 운영하는 서버, ③ 서울 리전이 있는 관리형 서비스(AWS, Firebase, Supabase, 네이버 클라우드 등)를 이야기했습니다. **고르지 않았습니다.**
   - 어떤 데이터를 꼭 서버로 받아야 하는지 정리하는 일도 아직 하지 않았습니다.
2. **푸시 알림**(앱이 닫혀 있을 때): 서버가 필요합니다. 하지 않기로도, 하기로도 정하지 않았습니다.
3. **앱 이름**: 정하지 않았습니다.
4. **사료 데이터베이스**: 디자인에는 사료 검색이 있지만 데이터 출처를 정하지 않았습니다.
5. **얼굴 촬영 기능**: 추후 기능입니다. 용도와 시기를 정하지 않았습니다.
6. **최종 글꼴**: 캔버스에 6종 비교가 있으나 다시 정하지 않았습니다.
